Install in a minute

This early version is signed but not yet notarized by Apple, so macOS asks you to confirm the first time.

  1. Download and open the zipDrag Aftercall into your Applications folder.
  2. Open it the first timeDouble-click Aftercall. If macOS says it can't verify the developer, open System Settings → Privacy & Security and click Open Anyway.
  3. Allow the microphone and system audioSo Aftercall can hear both you and the other people on the call.
  4. Turn on AI notesIf you use Claude Code, summaries use your existing Claude subscription automatically. Otherwise add an Anthropic API key in Settings → AI notes.
